# Review scope and decisions

Independent task reviews and whole-branch review accepted the toolkit's tensor contracts, raw DeepWave adapter, separate FWI/FWIGAN strategies, gradient isolation, continuation snapshots, CLI/notebook clients and CPU benchmark through the calibrated source at `7885070`. Subsequent scoped reviews approved the absent-device test fixture at `d31d28c`, benchmark metadata API correction at `2172137`, AMP calibration guard at `286e036`, field-labelled numerical diagnostics and narrow CUDA velocity-change ULP floor at `7339f63`, opt-in untimed repeatability diagnostic at `f54f251`, and test-only seeded penalty regression at `81010f6`. These reviews do **not** approve the failed CUDA equivalent-work comparison or merging the PR.

Two scientific decisions remain explicit:

1. Float32 physical coordinates that native DeepWave would truncate into a different grid cell are rejected; silently snapping them would violate geometry parity.
2. The stored 30 m Marmousi known-source coefficient is calibrated by `(3/30)^2 = 0.01`. Fine-grid 7 Hz generation and the FWIGAN 10 Hz initializer remain unchanged. Imported coefficients, surface/colocated geometry and different PML widths need separate validation.

The CUDA velocity-change floor applies to **one recovered float32 model ULP per cell only**; every other benchmark field retains its previous criterion. The actual RTX 4090 benchmark at `7339f63` still failed 44 comparison paths, including 522 of 2,800 velocity-change cells after the floor. The opt-in diagnostic's actual RTX 4090 run at `3b0b5d2` passed all 12 paired original/package epoch comparisons within tolerance while all 16 same-implementation replay comparisons failed bit-exact checks. The diagnostic was instrumented and untimed; it does not resolve that earlier material failure. The test-only seeded penalty regression proves matching 12 CPU beta draws and RNG endpoints from a shared seed-42 snapshot, without changing production RNG behavior. The [validation record](validation.md), [failed benchmark](gpu-benchmark-failure.json), and [diagnostic summary](gpu-repeatability-summary.json) preserve these distinct outcomes.

Both hosted CPU checks at `3b0b5d2` passed 215 tests with four optional CUDA skips each. The full RTX 4090 suite at that source passed 219/219, including all four CUDA checks; the later test-only seed regression has 20 focused CPU passes and pending hosted checks. There is no accepted all-workload CUDA timing/memory, full Marmousi convergence or modern-backend comparison. Pull request #1 is prepared for human review with these limits, not approved for merge.
